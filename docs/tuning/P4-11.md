# P4-11: the Desk assumptions

Harness: `tests/integration/Tuning/DeskBench.php` (group `tuning`). It seeds `docs/fixtures/queue-2026-11-09.json` with the pinned clock (2026-11-09 14:00, America/Los_Angeles), adds 300 synthetic published posts spread over the previous 400 days across the site's eight categories (through `Slots::insert()`), reads traffic from `FixtureStats` on `docs/fixtures/stats-sample.json`, sets each candidate value through the `masthead_config` filter, and prints one row per value. Environment: wp-env, WordPress 7.1.4, PHP 8.5.12.

Every default is kept: no decision rule fired, so `src/Config.php` is unchanged and the "after" row of each table is the "before" row.
